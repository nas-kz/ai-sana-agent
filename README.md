# AI-Sana — 3-кезең кеңесшісі

Оңтүстік Қазақстан медицина академиясына арналған қазақ, орыс және ағылшын тілдеріндегі ақпараттық веб-чат. Жауаптар төрт бағдарлама құжатына негізделеді, дереккөз бен бет көрсетіледі.

## Іске қосу

Node.js 22.13 немесе жаңарақ нұсқасын орнатыңыз. Репозиторийді жүктеп, қалтасында орындаңыз:

```sh
npm install
```

Осы қалтада `.env.local` файлын жасап, өз кілтіңізді енгізіңіз:

```dotenv
OPENAI_API_KEY=YOUR_API_KEY
OPENAI_MODEL=gpt-5.4-mini
```

```sh
npm start
```

Браузерде http://127.0.0.1:5180 ашыңыз. Бұл мекенжай тек сервер іске қосылған компьютерде жұмыс істейді. OpenAI API үшін жарамды кілт пен API балансы қажет. Кілт серверде сақталады, GitHub-қа жүктелмейді.

## Файлдар

- `page.tsx`, `globals.css` — үш тілдегі интерфейс.
- `route.ts` — құжаттарды іздеу және OpenAI сұрауы; жергілікті сервер оны Node.js үшін түрлендіреді.
- `local-server.mjs` — құрастыру және жергілікті HTTP сервер.
- `chunks.json`, `pages.json` — төрт PDF негізіндегі білім қоры.
- `source-1.pdf`–`source-4.pdf` — бастапқы бағдарлама және силлабустар.
- `ai-sana-github.zip` — бастапқы толық framework жобасының кілтсіз архиві.

Түбірдегі файлдар жергілікті іске қосуға бейімделген. Тексеру: `npm run build`. Интернетте жариялау үшін бөлек хостинг пен сұрауларды шектеу қажет.
